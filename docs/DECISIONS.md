# DECISIONS.md

Lightweight daily log of key design decisions.

| Date | Decision | Rationale |
|---|---|---|
| 2026-06-02 | Do not adopt LangGraph at this time; fix domain logic layer first | The most critical issues (stub candidates, fake embeddings, thin domain agents, weak guardrail) are domain-layer problems that LangGraph cannot solve. Public interface changes required for LangGraph adoption (LLMClient, Tool, Orchestrator, Specialist) would need 5+ ADRs and create unacceptable scope risk while domain logic is incomplete. Conditions for reconsideration: domain logic stabilized; session persistence becomes a production blocker; DAG parallelism a performance bottleneck. Full rationale in ADR/2026-06-02-langgraph-adoption.md. |
| 2026-06-02 | Remove stub candidate fallback in `_rank_candidates` immediately | Prohibited by AGENTS.md: "smart stubs that approximate real behavior instead of conforming to the schema contract." When `simulation_optimizer` returns no candidates, raise an explicit error rather than synthesizing MOQ-multiple placeholders. Tracked as T-001. |
| 2026-06-02 | Replace SHA-256 fake embeddings with a real embedding API call | `_make_embedding()` in `packages/memory/__init__.py` generates deterministic hash-based vectors with zero semantic similarity — a smart stub that violates AGENTS.md. Target: Anthropic or OpenAI `text-embedding-3-small`. Requires ADR before changing `MemoryStore` public interface (dimension changes from 192 to 1536/3072). Tracked as T-003. |
| 2026-06-02 | Adopt 3-block prompt caching pattern from agentic-system-mvp | Split system message into: (1) static base prompt with `cache_control: ephemeral`, (2) schema context with `cache_control: ephemeral`, (3) dynamic context without cache. Reduces input token cost without changing public interfaces. Applicable to `AgentRuntime.run()` in `packages/agent/runtime.py`. Tracked as T-008. |
| 2026-06-02 | Adopt LLM cost persistence: write per-call usage to `llm_usage` table | `BudgetGuard` in `packages/agent/llm/__init__.py` is in-memory only and resets on restart. Add `llm_usage` table and persist model, tokens, cost, and role per LLM call. Enables per-session and per-role cost analysis. Does not change public interfaces. Tracked as T-009. |
| 2026-06-02 | T-025 `/files` endpoint lives in `jobs.py` router, not a separate router file | All generated files are accessed in the context of jobs; a separate router would fragment a tightly coupled resource. No ADR required — no public interface Protocol changes. |
| 2026-06-02 | Mock mode activated via `MOCK_LLM=true` env var (server-side only); no UI toggle | Server-side env var is the only safe activation point: a UI toggle could accidentally disable LLM calls in production if the toggle state leaked across sessions. The `LLMClient` Protocol is unchanged — `ScenarioStubClaudeClient` implements the same interface. No ADR required (no public interface change). Tracked as P8 (T-059–T-062). |
| 2026-06-02 | Fix DAG execution to parallelize independent nodes with asyncio.gather | `run_dag_execution()` in `packages/agent/orchestrator/planning.py` processes ready nodes sequentially in a `for` loop, defeating the purpose of the DAG. Replace with `asyncio.gather()` over all dependency-free nodes. Preserves existing public interfaces. Tracked as T-002. |
